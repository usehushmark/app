# Hushmark direction

Hushmark is a privacy-payment interface on Solana. It integrates Privacy Cash for encrypted notes, client-side ZK proofs and pool withdrawals. It is not an independent privacy blockchain and has no issued native token.

The product flows are Unlock, Deposit, Sync private balance, and Withdraw. Ordinary public transfers are no longer the primary product. SDK integration does not itself establish audited security or funded end-to-end success.

Public-chain observers still see deposit and withdrawal endpoints and amounts. Protocol unlinkability is subject to metadata, anonymity-set and service assumptions described in /docs. The earlier reputation circuit remains separate research; it does not secure payments.
